# لوحة MikroTik المحمولة

لوحة محلية تعمل على هاتف أندرويد داخل Termux، وتقرأ بيانات MikroTik فقط.

## الوظائف الحالية
- حالة الاتصال بالراوتر.
- اسم الجهاز وإصدار RouterOS.
- استهلاك المعالج والذاكرة.
- عدد مستخدمي Hotspot المتصلين.
- حالة الواجهات وحجم البيانات.
- آخر السجلات.
- تحليل سريع للأعطال الظاهرة.

## التشغيل في Termux

1. فك الضغط عن الملف.
2. ادخل إلى المجلد.
3. شغّل:
   bash install.sh
4. ثم:
   python app.py
5. سيطلب:
   - عنوان الراوتر، الافتراضي 10.0.0.1
   - اسم المستخدم
   - كلمة المرور، ولن تظهر أثناء الكتابة
6. افتح متصفح الهاتف واكتب:
   http://127.0.0.1:8080

## الأمان
- البرنامج لا يخزن كلمة المرور.
- البرنامج للقراءة فقط من جهته، لكن صلاحيات المستخدم في MikroTik هي التي تحكم ما يستطيع الوصول إليه.
- يُفضّل إنشاء مستخدم MikroTik مخصص بصلاحية read فقط وعدم استخدام admin.
- يُفضّل تقييد IP → Services → API في Available From إلى عنوان هاتفك داخل الشبكة.

## إيقاف البرنامج
اضغط CTRL ثم C داخل Termux.
